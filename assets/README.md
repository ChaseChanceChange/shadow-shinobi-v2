# Shadow Shinobi Asset Library

This is the original source pool supplied for the fresh Shadow Shinobi build.

The archive currently contains 7,894 files across 22 folders. It is deliberately stored as a source/candidate library; production code should reference approved copies or derived assets from `assets/production/` rather than assuming every source file is ready for shipping.

Review status should eventually be tracked as: RAW, CANDIDATE, APPROVED, OPTIMIZED, IN_USE, RESERVED, REJECTED.
