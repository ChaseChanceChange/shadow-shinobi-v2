# World Memory

World Memory is a first-class game system. The authoritative event is recorded when a meaningful gameplay action happens. The system may later turn that fact into reputation, lore, achievements, rankings, rare encounters, relics or global events.

## New gear-memory interaction

A high-risk enhancement attempt can create a permanent chain:

```text
Gear + Enhancement Attempt
        ↓
Success or Failure
        ↓
World Event
        ↓
Fragments Returned
        ↓
Failure: Lost Relic Seed
        ↓
Future Exploration / Event
        ↓
Another Player Can Discover It
```

A relic produced from a destroyed item is deliberately weaker than the original, but it carries provenance in its structured payload. This gives catastrophic gear failure a second life without making failure equivalent to keeping the original power.

## Global event direction

Future world broadcasts can be triggered by thresholds such as:

- first server-wide Mythic destruction
- first +16 enhancement
- first Awakened weapon
- first world boss defeat
- unusual streaks of operative survival
- discovery of a relic whose origin is globally significant

The system must never invent a false event. It only promotes authoritative game facts.
