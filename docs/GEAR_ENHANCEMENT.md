# Gear & Enhancement Design

Gear is a primary progression pillar.

## Ritual rule

A player selects one target gear item and at least two additional gear pieces. The target plus all sacrifices are consumed by the attempt.

- Success: the target identity returns at the next enhancement level.
- Failure: the target is destroyed.
- Every consumed piece generates gear fragments.
- A failed high-value attempt may create a Lost Relic seed.
- Lost Relics are weaker echoes of the destroyed item's power.
- Lost Relics can later surface through exploration or world events.

## Why the target is consumed too

This makes the system genuinely high-stakes. The choice is not simply "spend materials to upgrade an item." The player is deciding whether three or more existing pieces are worth burning together for one possible leap.

## Visual composition

Do not generate unique artwork for every roll. Compose:

```text
Base Item + Rarity Frame + Enhancement Frame + Glow + Particles + Awakened Overlay
```

## Core weapons

Each operative can receive a personal core weapon. Core weapons carry a weapon family and talent-tree key. Equipping a weapon of sufficient rarity exposes progressively deeper talent nodes.
