# Shadow Shinobi Naming

All maintained code, data, UI and content use English.

Canonical examples:

- Operative
- Squad
- Gear
- Weapon
- Core Weapon
- Enhancement
- Awakened
- Transcendent
- Contract
- Training
- Essence
- Insight
- Standing
- Coin
- World Memory
- Lost Relic
- Relic Echo
- Talent Tree
- Set Value
- Gear Fragment

Stable content IDs should use prefixes such as:

```text
OPR-000001
EQP-000001
ART-000001
CTR-000001
MON-000001
BOS-000001
LOC-000001
REL-000001
AST-000001
```
