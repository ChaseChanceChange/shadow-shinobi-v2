# Content Authoring

New content should be data-first.

## Gear

Required fields:

- ID
- name
- slot
- rarity
- main stat
- substat pool
- set value
- visual layers
- talent tree key if weapon
- lore/provenance hooks

## World Memory event

Required:

- factual event type
- title
- summary
- structured payload
- timestamp
- player/global visibility

Never fabricate historical gameplay facts.
