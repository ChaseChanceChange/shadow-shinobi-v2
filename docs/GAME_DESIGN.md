# Shadow Shinobi Game Design Direction

## Core pillars

1. Squad building and operative identity.
2. Weapons and relics as the central progression layer.
3. High-risk enhancement where the player sacrifices at least three gear pieces, including the target.
4. World Memory that records real player history.
5. Lost Relics created from important failures and returned to the world.
6. Optional Living Wilds mode with an evolving ecosystem.

## Enhancement rule

A ritual consumes the target and at least two additional pieces. Success recreates the target at the next level. Failure destroys it. Every consumed piece contributes fragments back to the player/world economy.

Rare failures can create a weaker Lost Relic based on the destroyed item's provenance. High-value failures can produce global events.

## Core weapon rule

Every operative can have a personal Core Weapon. Rarity controls how much of the weapon's hidden Talent Tree becomes visible and usable when equipped.

## World Memory rule

Only authoritative facts can become memories. The system may interpret history but cannot invent it.

## Living Wilds

Living Wilds is intentionally a separate mode. It can become a more sophisticated ecosystem over time without making the core MMO mission loop depend on simulation complexity.
